## Overview

**Page Purpose:** 展示简历与JD的匹配分析结果——让快速判断者3秒内获取总分+投递建议，深度分析者有序深入细节，差距补足者找到行动路径。

**Entry Context:** API返回匹配结果 → 页面从加载态过渡到结果态

**User Mental State:**
- 快速判断者：急切想知道结论，不想被细节淹没
- 深度分析者：愿意逐条阅读，但要先被说服"值得细看"
- 差距补足者：准备找差距、学技能、改简历

**Main User Goal:** 获取明确的匹配分数、投递建议和可操作的下一步

**Business Goal:** 信息层级清晰 + 评分评估整合 + 视觉精致现代

### 设计决策理由

| 决策 | 理由 |
|------|------|
| Hero 区深色底 | 视觉焦点集中，评分环在深色背景下更突出——满足"3秒定位分数" |
| 评分环 + 评估合并 | 分数和结论不再割裂——快速判断者一站式获取"多少分 + 投不投" |
| Hero 区内含雷达图 | 五维分析是分数的支撑数据，放在 Hero 区内形成完整"第一眼"信息包 |
| Analysis 区浅色底 | Hero 之后切换到明亮的分析区，视觉有节奏变化，深→浅过渡自然 |
| 简历优化独立区 | 收口统一，不与分析卡片抢注意力 |
| 逐行动画入场 | 强化精致产品感——不是一次性全部弹出 |

## Component Specifications

### 1. Hero 区 — 深色背景容器

**Layout:** `bg-slate-900 rounded-2xl p-8`
**内部结构:** 两行

**Row 1: 评分 + 综合评估 (并排)**
- 左侧 35%: ScoreRing（放大版，SVG 160×160，在深色背景上使用蓝-紫渐变 + glow）
- 右侧 65%: 综合评估卡片（半透明深色底 `bg-white/5 backdrop-blur rounded-xl p-5`）
  - 匹配度分析文字（`text-slate-200`）
  - 面试概率 badge（fire/thumbsup/eyes/warning emoji + 文字）
  - 投递建议 verdict badge（建议投递/谨慎考虑/建议观望，彩色 badge）
  - 不建议投递条件列表

**Row 2: 五维分析**
- `bg-white/5 backdrop-blur rounded-xl p-5 mt-4`
- RadarChart + BarLegend 并排
- 每维度解读文字在柱形图下方

### 2. 评分环 (ScoreRing) — 放大重构

**当前问题:** 112px SVG 孤零零占一整行，浪费空间
**改版方案:**
- SVG 升级到 160×160px，环形图更饱满
- 深色背景上使用更鲜明的渐变 `blue-400→violet-400`
- glow 效果增强：`drop-shadow-[0_0_20px_rgba(99,102,241,0.3)]`
- 分数数字 36px，白色 `fill="#fff"`
- 标签"综合匹配度"用 `text-violet-300`
- 分数颜色保持动态变色（>=80 emerald / >=60 indigo / >=40 amber / <40 red）

### 3. 综合评估 (OverallAssessment) — 并入 Hero

**当前问题:** 独立一行，与评分环分离
**改版方案:**
- 与评分环并排呈现
- 半透明深色底，文字亮色
- verdict badge 保持语义色但加大加粗
- 匹配度分析文字精简到 80-100 字
- reasonsToReject 用暗色圆点列表

### 4. 五维雷达 + 柱形图 — 并入 Hero

**当前问题:** 在 Hero 外独立一个 Row，与评分关联感弱
**改版方案:**
- 雷达图 outer radius 提高，grid/axis 标签用 slate-400
- 雷达填充渐变匹配 Hero 色调
- 柱形图 bar 渐变与维度色保持一致
- 每维度 summary 解读文字在 bar 下方，text-slate-300

### 5. Analysis 区 — 三卡片行

**当前问题:** 三个卡片颜色过于粉彩（pastel），在整页中缺乏精致感
**改版方案:**
- 统一白色底卡片 + 左边框色彩标识（更精致）
  - 优势: 左边框 `border-l-4 border-l-emerald-500`
  - 短板: 左边框 `border-l-4 border-l-red-500`  
  - 补足: 左边框 `border-l-4 border-l-blue-500`
- 内页项目用更干净的 `bg-slate-50 rounded-lg p-3` 子卡片
- severity badge 保持红/琥珀/灰三级
- learningPath 步骤编号和 emoji 标识

### 6. 简历优化 — 独立区

**当前问题:** 与综合评估同一行，视觉权重不够
**改版方案:**
- 独立一行全宽卡片
- 左侧装饰条 violet-500
- 3 条改写建议横向排列（`grid-cols-3`）
- 每条：原文(strikethrough) → 优化(加粗) → 命中关键词(badge)
- `bg-white rounded-2xl ring-1 ring-slate-900/5 shadow-sm`
