## 1. Vision

> **从「诊断报告」到「行动指南」** — 把匹配结果页从冷冰冰的数据报表，变成一份精致现代、眼前一亮的产品体验。信息量足够，视觉效果同样重要。

## 3. Target Groups

### Priority 1: 快速判断者 (Quick Judge)
**来源**: 躺平阿杰 + 被裁老张
**行为模式**: 先看分数和结论，再决定要不要细看 — 决策效率优先于分析深度

### Priority 2: 深度分析者 (Deep Analyzer)
**来源**: 转行者小周 + 老手娜姐
**行为模式**: 逐条细看每一项分析，关注"为什么" — 要确认自身价值被充分识别

### Priority 3: 差距补足者 (Gap Filler)
**来源**: 应届小林
**行为模式**: 关注"差什么 + 怎么补" — 把结果页当学习路线图

## 4. Driving Forces

| 画像 | ➕ 正向驱动 | ➖ 负向驱动 |

| **深度分析者** | 确认优势被准确识别；看到优势命中JD要求；有说服力的决策支持 | 害怕经验被低估；担心转行能力不被认可；怕浪费时间 |
| **差距补足者** | 清晰看到差距在哪；获得可行动的补足步骤；看到可直接用的改写建议 | 害怕差距太大无从下手；担心补了没用；怕改写后失去真实性 |

## 5. Design Focus Statement

> **首要服务「快速判断者」** — 页面打开 3 秒内，Hero 区域传递总分 + 明确投递建议。**同时为「深度分析者」提供有序展开的分析细节，为「差距补足者」保持清晰的行动路径。** 视觉层级：**分数/结论 > 五维概况 > 行动建议 > 分析细节**。
