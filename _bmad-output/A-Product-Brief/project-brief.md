## Project Scope

**人岗匹配** — 简历与 JD 智能匹配结果页的整体布局视觉改版。覆盖范围：

- **Header** — 顶部导航栏（Logo + 示例数据标识）
- **InputPanel** — 输入区（ResumeCard 简历输入 + JdCard JD 输入 + MatchButton 匹配按钮）
- **ResultPanel** — 结果展示区（6 个子组件）：
  - ScoreRing — 综合匹配度环形评分图
  - RadarChart + BarLegend — 五维雷达图 + 柱形图解读
  - AnalysisCards — 三卡片（核心优势 + 短板分析 + 补足路线图）
  - OverallAssessment — 综合评估（适配度分析 + 投递建议）
  - ResumeOptimization — 简历优化改写建议
- **整体布局框架** — 页面容器、间距系统、视觉节奏

**平台**: 仅桌面端 Web（≥768px 视口）

**技术栈**: React 18 + Vite + Tailwind CSS 3 + Recharts（不变）

## Challenge / Opportunity

### 当前痛点

当前页面风格为"暖色极简 SaaS"，存在六个明确的视觉问题：

1. **色调沉闷** — stone 暖灰打底过于保守，缺乏活力与辨识度
2. **重点不突出** — 所有板块视觉权重均等，用户打开页面不知道该看哪里
3. **信息层级不清** — 综合评分、五维分析、优劣势卡片之间缺乏主次关系
4. **评分区空洞** — 一个大环形图孤零零占据整行，空间利用率低
5. **评分与评估割裂** — ScoreRing（评分）和 OverallAssessment（综合评估）分属不同行，逻辑上本应一体
6. **布局松散凌乱** — 三个独立 Row 各自为政，缺乏对齐和秩序感

**核心问题**: 页面像一堆独立卡片的堆叠，而不是一个有机的整体报告。

### 机会

将页面从「数据罗列」升级为「精致产品体验」——让求职者打开页面时感受到专业、现代、眼前一亮，像使用一个精心打磨的产品而非阅读一份数据报表。

## Design Goals

### 核心目标

**精致现代，眼前一亮** — 像一个精心设计的产品，而非卡片和数据的堆叠。

### 可衡量目标

| # | 目标 | 含义 |
|---|------|------|
| 1 | **建立清晰的信息层级** | 用户进入页面 3 秒内能找到综合评分（最重要信息），5 秒内理解五维匹配概况，10 秒内看到行动建议 |
| 2 | **评分与评估整合** | 环形图 + 综合评语 + 投递建议合并为一个有机的「Hero 区域」，不再割裂 |
| 3 | **统一视觉节奏** | 用统一的间距、对齐、分区替代当前松散的三行堆叠，让页面有呼吸感和秩序感 |
| 4 | **色彩焕新** | 摆脱沉闷的 stone 暖灰基调，采用更精致现代的配色方案，让页面"亮"起来 |
| 5 | **重点强化** | 关键信息（匹配分、投递建议）有视觉焦点，次要信息有序退后 |
